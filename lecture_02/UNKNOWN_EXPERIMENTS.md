# Распознавание `unknown`

## Задача и условия

Модель классифицирует изображения 25 пород собак. Для изображения, которое не
похоже ни на одну известную породу, нужно вернуть `unknown`.

Все эксперименты используют один checkpoint:
`models/model_25_classes_validation.pth`. Известные классы разбиты на 1994
изображения для train, 498 для validation и 2486 для test. В качестве первого
набора unknown использованы 1183 изображения 12 пород кошек из Oxford-IIIT Pet.

Порог каждого метода выбирается по validation и фиксируется до проверки на
test. Ограничение для известных изображений — не более 5% ложных отказов.

## Последовательность экспериментов

### U01. Модель без отказа (closed-set classification)

Проблема: обычный классификатор всегда выбирает одну из 25 пород.

Действие: измеряем ответы модели на известных собаках и кошках.

Результат:

- accuracy на известных собаках — 92,24%;
- все кошки получили название одной из пород собак;
- 80 из 1183 кошек получили уверенность не ниже 90%.

Вывод: confidence сама по себе не гарантирует правильность ответа. Но она может
быть полезным сигналом для частичного отказа, поэтому следующим шагом проверяем
порог по confidence.

### U02. Порог confidence (confidence thresholding / selective classification)

Гипотеза: хотя высокая confidence не гарантирует правильность, низкая confidence
может чаще встречаться на неизвестных изображениях.

Действие: если максимальная softmax confidence ниже порога, возвращаем
`unknown`.
Порог выбран по validation при ограничении ложного отказа 5%.

Результат на test:

- порог — `0,546255`;
- обнаружено 707 из 1183 кошек — 59,76%;
- ошибочно отклонено 111 из 2486 собак — 4,47%;
- accuracy на всех известных собаках — 90,06%.

Вывод: гипотеза подтвердилась частично. Порог по confidence отсекает часть кошек,
но 40,24% всё ещё принимаются за собак. Значит, confidence полезна как сигнал,
но недостаточно хорошо отделяет unknown от известных изображений.

### U03. Разница двух лучших ответов (margin-based rejection)

Проблема: максимальная оценка не показывает, насколько первый ответ отличается
от второго.

Действие: вычисляем `p1 - p2`. Если разница ниже порога, возвращаем `unknown`.

Результат на test:

- порог — `0,231380`;
- обнаружено 549 из 1183 кошек — 46,41%;
- ошибочно отклонено 108 из 2486 собак — 4,34%;
- accuracy на всех известных собаках — 90,06%.

Вывод: гипотеза не подтвердилась. U03 обнаружил на 158 кошек меньше, чем U02,
при сокращении ложных отказов только на 3 изображения.

### U04. Расстояние до центров пород (feature-space distance / prototype-based rejection)

Проблема: модель может быть уверенной, даже когда изображение не похоже на
известные классы.

Действие: получаем feature embeddings перед последним слоем ResNet18 и для
каждой породы строим class prototype (центр признаков) по train. Для нового
изображения вычисляем cosine distance до ближайшего prototype. Если расстояние
выше порога, возвращаем `unknown`. Порог выбран только по известным validation.

Результат на test:

- порог — `0,225643`;
- обнаружено 1090 из 1183 кошек — 92,14%;
- ошибочно отклонено 114 из 2486 собак — 4,59%;
- accuracy на всех известных собаках — 89,18%;
- хуже всего распознавались кошки породы Sphynx: 57 из 100 обнаружены.

Вывод: U04 значительно лучше U02 обнаруживает кошек при почти том же числе
ложных отказов. Цена метода — немного меньшая accuracy на известных собаках:
он иногда отклоняет собаку, которую классификатор назвал правильно.

одном checkpoint и проверено на кошках. Оно ещё не проверяет все возможные виды
unknown.

`results/u02_confidence_threshold/`, `results/u03_margin_threshold/` и

## Предсказание одного изображения

```bash
python -m lecture_02.predict data/data_real/sima.jpg \
    --model 25_classes_validation --unknown u04
```

Команда показывает итоговый ответ, top-k пород, оценку и порог. При ответе
`unknown` top-k всё равно показывает, какие породы модель рассматривала.

Показательный пример: на одной фотографии классификатор выбрал `Shiba Inu` с
уверенностью 77,3%. U02 и U03 приняли этот ответ, а U04 вернул `unknown`, потому
что расстояние до ближайшего центра пород оказалось выше порога. Это показывает,
что U04 проверяет сходство изображения с известными породами, а не только
уверенность классификатора.

## Дальнейшие шаги

1. Собрать отдельный test-набор из неизвестных пород собак, других животных и
   предметов.
2. Проверить на нём U02 и U04 с уже зафиксированными порогами.
3. Разобрать ошибки U04 по группам unknown и по известным породам.
4. Если одного центра недостаточно, проверить несколько центров или учитывать
   разброс признаков внутри каждой породы.
5. После этого решить, нужен ли обучаемый 26-й класс `unknown`.
