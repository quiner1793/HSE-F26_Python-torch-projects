# Распознавание unknown

## Задача

Для изображения одной из 25 известных пород модель должна назвать породу.
Для остальных изображений ожидается `unknown`: другие животные, предметы,
а также породы собак, которых нет среди 25 классов.

Начальная модель — checkpoint эксперимента `06_validation_early_stopping`.
В первых опытах `unknown` будет результатом отказа от ответа по правилу.
Отдельный обучаемый 26-й класс проверим позже. Неуверенность между двумя
известными породами сама по себе не означает, что изображение неизвестное.

## Данные и условия сравнения

- **Известные породы:** используем разбиение эксперимента `06`: 1994 train,
  498 validation и 2486 test. Аугментация применяется только при обучении.
- **Первый набор unknown:** 12 пород кошек Oxford-IIIT Pet, не входящих в
  наш классификатор. `trainval` используем для настройки правил, `test` для
  оценки. Этот опыт проверяет отказ на кошках, а не на любых чужих изображениях.
- **Расширенная проверка:** отдельно соберём другие виды животных, предметы
  и собак неизвестных пород. В Oxford-IIIT Pet все 25 собачьих пород уже
  известны модели, поэтому неизвестных собак нужно брать из другого источника.
- **Разделение unknown:** заранее фиксируем train / validation / test,
  исключаем дубликаты и снимки одного объекта между частями. Часть категорий
  оставляем только для test, чтобы проверить новые виды неизвестных объектов.
- **Сравнение:** для пороговых методов используем один checkpoint и одни
  изображения. Пороги выбираем по validation и фиксируем до оценки на test.
  Test уже использовался в предыдущих опытах, поэтому результаты считаем
  учебным сравнением; для независимой итоговой проверки нужен новый набор.

## План экспериментов

| Опыт | Проблема и гипотеза | Что проверяем |
| --- | --- | --- |
| U01: без отказа | Сейчас модель всегда выбирает известную породу. | Какую уверенность она выдаёт на известных и неизвестных изображениях; есть ли уверенные ошибки. |
| U02: порог уверенности | Гипотеза: у неизвестных изображений максимальная softmax-оценка чаще ниже. | Если `max_probability < threshold`, выдаём `unknown`. Подбираем порог без переобучения. |
| U03: разница двух ответов | Одной максимальной оценки может не хватать. Гипотеза: небольшой отрыв первого ответа от второго помогает находить unknown. | Отказываемся при `p1 - p2 < threshold`; сравниваем с U02 при одинаковом допустимом отказе на известных породах. |
| U04: расстояние до известных пород | Softmax может быть уверенным даже на чужом изображении. Гипотеза: unknown находится далеко от признаков всех известных пород. | Строим центр каждой породы по известному train и отказываемся, если изображение далеко от всех центров. Порог выбираем только по известным validation. |
| U05: расширенная проверка | Результат на кошках не описывает весь unknown. | Сравниваем U02 и U04 на других животных, предметах и неизвестных породах собак. Пороги по этим данным не меняем. |

Все опыты используют один обученный checkpoint. U01–U05 не переобучают сеть.
Unknown-изображения нужны для проверки, но U04 не использует их ни для
построения центров пород, ни для выбора порога.

## Запуск U01

Из корня `torch_projects` с активированным окружением:

```bash
python -m lecture_02.experiments.u01_unknown_baseline
```

Нужны checkpoint и `experiment.json` опыта `06`. Из его конфигурации берутся
seed и доля validation для восстановления разбиения. U01 загружает готовые
веса и выполняет только предсказания, на GPU при доступной CUDA.

Отдельно оцениваются известные и неизвестные изображения на validation и test.
В отчёте «уверенная ошибка» означает ошибочный ответ с softmax-оценкой не ниже
90%. Это фиксированный показатель для диагностики, а не порог выдачи unknown.
Кривая отказов строится только по validation; рабочий порог пока не выбирается.

## Запуск U02

```bash
python -m lecture_02.experiments.u02_confidence_threshold
```

Использует `experiment.json` U01; обучение, загрузка модели и GPU не нужны.
Порог выбирается только по validation: максимум обнаруженных unknown при
ложном отказе не более 5%. При равном результате выбирается меньший ложный
отказ, затем меньший порог. Test используется после выбора порога.
Результаты сохраняются отдельно в `results/u02_confidence_threshold/`.

Правило одинаково для отчёта и `predict_image(..., threshold=...)`:
оценка строго ниже порога даёт `unknown`, равная порогу принимается.
Точный порог хранится в `experiment.json`; он относится к checkpoint,
контрольная сумма которого записана в этом файле.

## Запуск U03

```bash
python -m lecture_02.experiments.u03_margin_threshold
```

Использует те же предсказания U01, без обучения и GPU. Оценка — разница между
двумя лучшими ответами: например, для 0,55 и 0,40 отрыв равен 0,15.
Если отрыв меньше порога, выдаём `unknown`. Маленький отрыв означает, что
модель сомневается между породами, но не обязательно видит неизвестный объект.

Порог подбирается по validation с тем же ограничением ложного отказа в 5%,
что и в U02. Результаты: `results/u03_margin_threshold/`.
Для отдельной картинки: `predict_image(..., threshold=..., score="margin")`.
Точный порог берём из `experiment.json` U03; возвращаемая уверенность по-прежнему
равна максимальной softmax-оценке, а не отрыву.

## Запуск U04

```bash
python -m lecture_02.experiments.u04_feature_distance
```

U04 не обучает нейросеть. Для каждого изображения берутся 512 признаков перед
последним слоем ResNet18. Признаки нормализуются, после чего по известному
train вычисляется средний вектор — центр каждой из 25 пород.

Для нового изображения ищется ближайший центр. Большое косинусное расстояние
означает, что изображение не похоже ни на одну известную породу. Порог
выбирается по известным собакам из validation так, чтобы ложный отказ был не
выше 5%. Кошки используются только на test и не влияют на порог.

Результаты сохраняются в `results/u04_feature_distance/`. Запуск выполняет
только получение признаков готовой моделью; изменение её весов не происходит.

## Критерии качества

1. **Обнаружение unknown:** доля неизвестных изображений, получивших `unknown`.
2. **Ложный отказ:** доля известных собак, ошибочно получивших `unknown`.
3. **Правильная порода на всех известных изображениях:** отказ тоже считается
   ошибкой. Это защищает от кажущегося улучшения за счёт отказа на сложных собаках.
4. **Точность среди принятых ответов и доля принятых:** насколько можно доверять
   ответам и как часто модель вообще называет породу.

Начальный критерий выбора порога: обнаружить максимум unknown на validation
при ложном отказе на известных породах не более 5%. Для U02 и U03 ограничение
одинаковое; достигнутый ложный отказ на test сообщаем отдельно. Проверяем также
отказы по каждой породе, особенно среди похожих терьеров.
Softmax-оценка не является гарантированной вероятностью правильного ответа.

В U04 unknown-validation не используется. Порог равен границе, за которой
оказывается не более 5% известных validation-изображений. Это не оптимизирует
результат на кошках и позволяет проверить перенос правила честнее.

## Результаты и визуализации

| Опыт | Порог | Обнаружение unknown (test) | Ложный отказ (test) | Accuracy на всех известных (test) | Визуализация |
| --- | --- | ---: | ---: | ---: | --- |
| U01: без отказа | Нет | 0,00% | 0,00% | 92,24% | [Уверенность](results/u01_unknown_baseline/score_distribution.png) · [Компромисс отказов](results/u01_unknown_baseline/rejection_tradeoff.png) |
| U02: порог уверенности | 0,546255 | 59,76% | 4,47% | 90,06% | [Уверенность](results/u02_confidence_threshold/score_distribution.png) · [Компромисс отказов](results/u02_confidence_threshold/rejection_tradeoff.png) |
| U03: разница двух ответов | 0,231380 | 46,41% | 4,34% | 90,06% | [Разница ответов](results/u03_margin_threshold/score_distribution.png) · [Компромисс отказов](results/u03_margin_threshold/rejection_tradeoff.png) |

U02 на test обнаружил 707 из 1183 кошек, но отказал 111 из 2486 известных
собак. Принято 95,53% известных изображений; accuracy среди них — 94,27%.
Это отличается от accuracy на всех известных (90,06%), где отказ считается
ошибкой. Больше всего ложных отказов у American Pit Bull Terrier (16,00%),
Staffordshire Bull Terrier (13,48%) и Beagle (12,00%).

U03 на validation обнаружил 47,81% unknown против 62,79% у U02 при одинаковых
24 ложных отказах из 498 собак. На test обнаружены 549 из 1183 кошек,
ложный отказ — 108 из 2486 собак. По сравнению с U02 обнаружено на 158 кошек
меньше, а ложных отказов всего на 3 меньше. Для следующего опыта сохраняем U02:
он лучше по критерию выбора на validation; test подтверждает это наблюдение.

На test средняя уверенность составляет 92,51% для известных собак и 51,62%
для кошек. При этом 80 из 1183 кошек (6,76%) получают ошибочный ответ с
уверенностью не ниже 90%.

### Как читать «Возможности порога на validation»

График показывает, что получилось бы при разных порогах: если оценка ниже
порога, выдаём `unknown`, иначе называем породу. В U01 и U02 оценка — максимум
softmax, в U03 — разница двух лучших ответов.

- **Ось X:** процент известных собак, которым ошибочно отказали.
- **Ось Y:** процент кошек, правильно определённых как unknown.
- **Каждая точка:** результат одного порога; сам порог не нанесён на оси.
- **Красная линия:** выбранное ограничение в 5% ложных отказов на известных.

При повышении порога модель отказывает чаще: обнаруживает больше кошек, но
теряет больше знакомых собак. Поэтому желательны точки ближе к левому верхнему
углу. Точка (100%, 100%) означает отказ всем и практически бесполезна.

Пример по validation: порог около 0,546 даёт 62,79% обнаруженных unknown
(746 из 1188 кошек) при 4,82% ложных отказов (24 из 498 собак).
Это возможность порогового правила, а не результат U01 с включённым отказом.
В U02 порог фиксируется по validation, затем проверяется на test; ограничение
5% на validation не гарантирует такую же долю отказов на test.

Для каждого опыта сохраняем четыре файла:

- `report.txt`: основные метрики и короткий вывод;
- `experiment.json`: checkpoint, состав выборок, правило, порог и полные метрики;
- `score_distribution.png`: распределение оценки для известных и неизвестных;
- `rejection_tradeoff.png`: сколько unknown обнаруживаем при разном ложном отказе.

JSON также содержит оценки каждого изображения, исходные индексы и классы,
контрольные суммы checkpoint и файлов разметки. Эти данные позволят сравнить
пороговые методы на одних и тех же предсказаниях.

## Вывод

1. **U01: проверили модель без отказа.** Accuracy на известных собаках — 92,24%,
   но все кошки получили название собачьей породы. В среднем уверенность на
   кошках ниже, хотя 6,76% ответов имеют уверенность не ниже 90%.
   Следующий опыт U02 проверит, сколько неизвестных можно отсеять одним порогом
   при ограниченном числе ложных отказов на известных породах.

2. **U02: добавили порог уверенности.** На validation выбрали порог 0,546255.
   На test обнаружили 59,76% кошек при 4,47% ложных отказов на собаках.
   Проблема: 40,24% кошек всё ещё принимаются за собак, а часть знакомых пород
   теряется. Следующий опыт U03 проверит разницу между двумя лучшими ответами
   при том же ограничении ложного отказа на validation.

3. **U03: проверили разницу двух лучших ответов.** На test обнаружили 46,41%
   кошек при 4,34% ложных отказов. Гипотеза улучшения не подтвердилась:
   результат хуже U02 уже на validation. Маленький отрыв не оказался более
   полезным признаком неизвестного изображения на этих данных. Следующий опыт
   U04 проверит другой подход: расстояние до признаков известных пород без
   использования unknown при выборе порога.

## Возможные улучшения

После U04: расширить test разными группами unknown и сравнить U02 с U04 при
одинаковом ограничении ложных отказов. Дополнительно можно заменить один центр
на несколько центров для каждой породы или учитывать разброс признаков внутри
породы, если один средний вектор описывает её недостаточно хорошо.
