# Эксперименты

Команды выполняются из корня `torch_projects` с активированным окружением.
При наличии CUDA PyTorch автоматически использует GPU.

## Запуск

```bash
python -m lecture_02.experiments.01_baseline_5
python -m lecture_02.experiments.02_baseline_25
python -m lecture_02.experiments.03_finetune_layer4
python -m lecture_02.experiments.04_finetune_layer4_lr1e3
python -m lecture_02.experiments.05_finetune_with_augmentation
```

Существующий checkpoint загружается повторно. Для полного переобучения нужно
удалить соответствующий файл из `models/` или задать новый `model_path`.

## Вывод

При переходе от 5 к 25 классам accuracy снизилась с 99,20% до 90,39%.
Это ожидаемый результат: модель выбирает ответ из большего числа пород, среди
которых появились внешне похожие классы. Например, Beagle конкурирует с
Basset Hound, а несколько пород типа «буль» часто путаются между собой.

В baseline обучался только последний линейный слой `fc`. Основная часть
ResNet18 оставалась замороженной и использовала признаки, полученные при
обучении на ImageNet. Эти признаки хорошо описывают общие объекты, но не всегда
улавливают небольшие различия в форме головы, ушей, корпуса и окрасе породы.

Fine-tuning последнего блока `layer4` с lr 0.0001 почти не повлиял на результат:
accuracy выросла только до 90,63%. После увеличения lr до 0.001 модель смогла
сильнее адаптировать признаки под породы собак, и accuracy выросла до 91,51%.
Одновременно train accuracy достигла 98,96%, поэтому увеличился риск
переобучения: модель запомнила обучающие изображения лучше, чем научилась
работать с новыми.

Аугментация случайно меняет кадрирование, отражение и цвет обучающих изображений.
Благодаря этому модель видит больше вариантов одного изображения и меньше
зависит от конкретного фона или положения собаки. Этот вариант дал лучший
общий результат — 91,91%, а train accuracy снизилась до 97,27%, что указывает
на уменьшение переобучения.

Наиболее сложной остаётся группа `American Pit Bull Terrier`,
`Staffordshire Bull Terrier`, `American Bulldog` и `Boxer`. Общая accuracy
выросла, но улучшения распределились между классами неравномерно. Поэтому при
дальнейшем сравнении моделей важно смотреть не только на одну итоговую цифру,
но и на accuracy по классам и confusion matrix.

## Дальнейшие улучшения

1. **Добавить validation-выборку.** Сейчас параметры экспериментов сравниваются
   по test-выборке. Лучше отделить часть `trainval` для выбора learning rate,
   числа эпох и аугментаций, а test использовать один раз для итоговой оценки.

2. **Добавить early stopping и scheduler.** Early stopping завершит обучение,
   когда качество на validation перестанет расти. Scheduler будет постепенно
   уменьшать learning rate, чтобы в конце обучения точнее настроить веса и не
   испортить уже найденные признаки слишком крупным шагом.

3. **Увеличить число эпох fine-tuning.** Пять эпох могут быть недостаточны для
   адаптации `layer4`. Увеличивать их следует вместе с validation, early stopping
   и scheduler, иначе модель может сильнее переобучиться.

4. **Повторить лучшие настройки с несколькими seed.** Начальная инициализация и
   порядок изображений влияют на результат. Средняя accuracy по нескольким
   запускам покажет, является ли улучшение устойчивым, а не случайным.

5. **Сравнить более сильные backbone.** ResNet18 компактна и быстра, но модель
   с более выразительными признаками может лучше различать похожие породы.
   Сравнивать модели нужно при одинаковом разбиении данных и режиме обучения.

6. **Отдельно работать со сложными классами.** Полезно проверить разметку и
   изображения пород, которые часто путаются, а затем попробовать более точное
   кадрирование собаки или дополнительные примеры. Metric learning и
   contrastive loss могут дополнительно научить модель сближать изображения
   одной породы и разделять визуально похожие породы.
