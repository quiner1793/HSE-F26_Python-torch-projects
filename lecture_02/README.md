# Лекция 2: классификация пород

Базовое задание и эксперименты используют одну реализацию из `common`.
Файл эксперимента содержит только описание, `ExperimentConfig` и `main()`.
В наборе из 25 классов Oxford-IIIT Pet есть как собаки, так и кошки.

## Запуск

Из папки `torch_projects` (с активированным окружением):

```bash
python -m lecture_02.experiments.01_baseline_5
python -m lecture_02.experiments.02_01_base_25_classes
python -m lecture_02.experiments.02_02_diagnosis_lower_accuracy
python -m lecture_02.experiments.02_03_finetunning
python -m lecture_02.experiments.02_04_augmentation
```

Базовое задание также запускается командой `python main.py` из `lecture_02`
или `python -m lecture_02.main` из `torch_projects`.
Эксперименты запускайте как модули (`-m`), чтобы Python видел пакет `lecture_02`.
Пути к данным, моделям и результатам вычисляются относительно `lecture_02`,
а не текущей рабочей папки. Нужны torch, torchvision, pillow и matplotlib для графиков.

## Где находится логика

| Файл в common | Ответственность |
| --- | --- |
| `classes.py` | Упорядоченные наборы 5 и 25 классов |
| `config.py` | Устройство и пути |
| `dataset.py` | Выбор классов, перенумерация меток, датасеты и загрузчики |
| `transforms.py` | Стандартная подготовка и аугментация train |
| `model.py` | Создание ResNet18 и замена классификатора |
| `train.py` | Выбор обучаемых слоёв, единый цикл обучения, checkpoint |
| `evaluate.py` | Accuracy, матрица ошибок, графики и диагностика |
| `predict.py` | Предсказание для отдельной картинки |
| `experiment.py` | Конфигурация и общий сценарий запуска |

## Как изменить или добавить эксперимент

Скопируйте небольшой файл эксперимента и измените его `CONFIG`:

- `classes`: упорядоченный набор классов; можно задать свой набор любой длины.
- `model_path`, `results_dir`: отдельные пути для новой гипотезы.
- `epochs`, `batch_size`, `learning_rate`, `momentum`: параметры обучения.
- `backbone_lr=None`: обучается только `fc`; число, например `0.0001`, включает `layer4`.
- `augmentation=True`: случайные преобразования только обучающей выборки.
- `evaluate_only=True`: требуется существующий checkpoint, обучение не запускается.
- `diagnosis=True`: дополнительные графики и список наиболее частых ошибок.
- `reuse_checkpoint=False`: переобучение с ImageNet-весов; результат заменит `model_path`.
- `image_path`: необязательное фото для проверки после оценки.

По умолчанию существующая модель загружается, а отсутствующая обучается.
Имена прежних моделей и каталогов результатов сохранены. Формат checkpoint
(`model_state`, `classes`) совместим с прежним. Классы и их порядок проверяются
перед оценкой; при несовпадении выполнение прерывается.
Параметры обучения не хранятся в старых checkpoint: при изменении настроек
задавайте новый `model_path` или явно отключайте повторное использование.

Числа 90.65% и 91.13% больше не зашиты в код: сравнивайте фактические отчёты
соответствующих запусков. Диагностика использует тот же расчёт метрик, что и
обычная оценка. Как и раньше, `model.train()` обновляет статистики BatchNorm
даже в блоках с замороженными параметрами; это сохранено при рефакторинге.

## Дальнейшие эксперименты с unknown

Методы unknown пока не реализованы — их параметры и протокол будут определены отдельно.
Threshold и margin следует реализовать общей функцией принятия решения в `common`
и использовать её и в `evaluate.py`, и в `predict.py`. Обучаемый класс unknown
потребует общей подготовки дополнительных данных в `dataset.py` и добавления
класса в набор меток. В файлах экспериментов должны оставаться только настройки
конкретного метода, без копирования циклов обучения и оценки.

## Быстрые проверки

Из `torch_projects`:

```bash
MPLBACKEND=Agg python -m unittest discover -s lecture_02/tests -v
```

Проверки используют маленькую сеть и искусственные данные, не скачивают веса
и Oxford-IIIT Pet. Полное обучение и сравнение accuracy выполняются отдельно.
