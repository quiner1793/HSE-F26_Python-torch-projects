# Классификация пород собак

Проект классифицирует изображения пород собак из Oxford-IIIT Pet с помощью
ResNet18, предобученной на ImageNet. Поддерживаются наборы из 5 и 25 классов,
обучение классификатора, partial fine-tuning, аугментация и оценка качества.

## Структура

```text
lecture_02/
├── predict.py     предсказание по одному изображению
├── common/       общая логика данных, модели, обучения и оценки
├── experiments/  конфигурации экспериментов
├── models/       сохранённые checkpoint моделей
├── results/      метрики, отчёты и графики
└── tests/        автоматические проверки общей логики
```

### Модули `common`

| Файл | Назначение |
| --- | --- |
| `classes.py` | Наборы и порядок классов |
| `config.py` | Устройство и пути проекта |
| `dataset.py` | Загрузка Oxford-IIIT Pet, фильтрация классов и DataLoader |
| `transforms.py` | Предобработка и аугментация изображений |
| `model.py` | Создание ResNet18 и классификатора |
| `train.py` | Настройка обучаемых слоёв, обучение и checkpoint |
| `evaluate.py` | Метрики, отчёт и графики |
| `unknown.py` | Проверка порогов уверенности на известных и неизвестных изображениях |
| `open_set.py` | Расстояние до известных пород и предсказание unknown для фото |
| `predict.py` | Предсказание для одного изображения |
| `experiment.py` | Общий сценарий запуска эксперимента |

Каждый эксперимент задаётся через `ExperimentConfig` и использует реализацию
из `common`. Результаты запуска содержат краткий отчёт, полный JSON с
конфигурацией и метриками, accuracy по классам и confusion matrix.

Команды запуска и результаты: [EXPERIMENTS.md](EXPERIMENTS.md).

Запуск предсказания и результаты распознавания unknown: [UNKNOWN_EXPERIMENTS.md](UNKNOWN_EXPERIMENTS.md).
