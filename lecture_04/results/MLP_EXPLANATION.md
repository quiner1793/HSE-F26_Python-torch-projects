# Конспект: модели для предсказания временного ряда

## Задача

Мы решаем задачу регрессии: по прошлым значениям цены предсказываем следующее
значение.

Если `window = 20`, то модель получает:

```text
[price(t-20), price(t-19), ..., price(t-1)]
```

И должна предсказать:

```text
price(t)
```

Все модели работают в формате:

```text
sequence -> one value
```

## Подготовка данных

Перед обучением цены нормализуются:

```text
scaled = (price - mean) / std
```

Так модели проще обучаться, потому что значения становятся ближе к нулю и имеют
более стабильный масштаб.

Для графика значения переводятся обратно:

```text
price = scaled * std + mean
```

Метрики сейчас считаются в scaled-пространстве, а график строится в реальных
ценах.

## Baseline

Baseline - простое правило:

```text
prediction = price(t-1)
```

То есть следующий день считается равным последнему известному значению. Для
финансовых рядов это сильная отправная точка. Нейросеть имеет смысл только если
она дает ошибку меньше baseline.

## Метрики

Мы сравниваем предсказание `pred` с настоящим значением `target`.

MSE:

```text
MSE = mean((pred - target)^2)
```

MSE сильнее штрафует большие ошибки.

MAE:

```text
MAE = mean(abs(pred - target))
```

MAE показывает средний размер ошибки. Чем ниже MSE и MAE, тем лучше.

## MLP

MLP (Multi-Layer Perceptron) - полносвязная сеть. Она получает окно прошлых
значений как обычный вектор признаков.

В коде:

```python
nn.Linear(window, 64)
nn.ReLU()
nn.Linear(64, 1)
```

MLP может выучить нелинейные зависимости внутри окна, но у нее нет настоящей
памяти. Она не читает ряд последовательно, а смотрит на все 20 значений сразу.

Память MLP:

- скрытого состояния между шагами нет;
- порядок значений учитывается только через позиции во входном векторе;
- длинные зависимости доступны только если они помещаются в фиксированное окно.

Результат MLP:

```text
Baseline MSE: 0.005352
Baseline MAE: 0.052878
MLP MSE:      0.008279
MLP MAE:      0.068374
```

MLP хуже baseline, значит текущая модель не улучшила простое правило
"следующее значение примерно как последнее".

## Simple RNN

Simple RNN - базовая рекуррентная модель. Она читает последовательность по одному
значению за шаг:

```text
price(t-20) -> price(t-19) -> ... -> price(t-1)
```

На каждом шаге RNN обновляет скрытое состояние `h`. Это состояние можно понимать
как краткую сводку того, что модель уже увидела.

Память Simple RNN:

- на каждом шаге новое состояние зависит от текущего значения и прошлого
  состояния;
- вся информация о прошлом сжимается в один вектор `h`;
- старые события могут быстро забываться;
- при длинных последовательностях Simple RNN часто хуже удерживает далекий
  контекст.

Simple RNN полезна как базовая модель с памятью. Ее стоит сравнивать с LSTM и
GRU, чтобы понять, дает ли более сложная память реальное улучшение.

## LSTM

LSTM (Long Short-Term Memory) - рекуррентная модель с более развитой памятью.
Она тоже читает ряд по шагам, но хранит два состояния:

```text
h - скрытое состояние
c - состояние памяти
```

Скрытое состояние `h` используется как текущая сводка для предсказания.
Состояние памяти `c` помогает переносить важную информацию через несколько
шагов.

Память LSTM управляется воротами:

- forget gate решает, что забыть из прошлой памяти;
- input gate решает, какую новую информацию записать;
- output gate решает, какую часть памяти показать наружу через `h`.

За счет этих ворот LSTM может лучше удерживать важные зависимости и меньше
страдать от быстрого забывания, чем Simple RNN.

Результат LSTM:

```text
Baseline MSE: 0.005352
Baseline MAE: 0.052878
LSTM MSE:     0.021341
LSTM MAE:     0.118044
```

LSTM хуже baseline и MLP. Это значит, что наличие памяти само по себе не
гарантирует хороший прогноз. На шумном финансовом ряде модель может учить шум
или требовать других настроек.

## GRU

GRU (Gated Recurrent Unit) - рекуррентная модель с памятью, похожая на LSTM, но
проще. У GRU нет отдельного состояния памяти `c`: она использует только скрытое
состояние `h`.

Память GRU управляется двумя основными воротами:

- update gate решает, сколько информации из прошлого состояния сохранить;
- reset gate решает, сколько прошлого учитывать при обработке нового значения.

GRU обычно имеет меньше параметров, чем LSTM. Поэтому она может обучаться быстрее
и стабильнее на небольших данных.

Идея GRU:

- сохранить главное из прошлого;
- добавить полезную новую информацию;
- не усложнять модель отдельной ячейкой памяти, как в LSTM.

GRU стоит проверить после LSTM, потому что она часто дает близкое качество, но
может быть устойчивее на коротких и шумных рядах.
